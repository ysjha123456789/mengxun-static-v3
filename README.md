# 梦寻：梦境记录与社交系统精简静态原型

这是一个面向比赛展示的本地静态交互原型，产品结构收束为三个核心空间：

- 共鸣星空：浏览相似梦、匿名公开梦和梦友授权梦。
- 记梦：输入梦境，并明确选择私人收藏、匿名公开或树洞纸条。
- 个人星图：查看自己的梦境轨迹、梦友关系和逐场授权状态。

在线访问：<https://ysjha123456789.github.io/mengxun-static-v3/>

桌面端与手机竖屏使用不同的空间排布。手机端采用两层顶部导航、重新编排的六星星空、左右环绕主星的个人星图，以及从底部展开的梦纸和保存选择层。

## 范围说明

项目仅使用原生 HTML、CSS 和 JavaScript，不连接账户、数据库、语音、分析、匹配或社交后端。所有人物、梦境和关系数据均为本地演示数据；刷新页面后恢复初始状态。
